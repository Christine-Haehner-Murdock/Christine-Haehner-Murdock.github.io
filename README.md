# Christine Hähner-Murdock — AI Safety Beyond the Single Request

Static scholarly site for [christine-haehner-murdock.github.io](https://christine-haehner-murdock.github.io/).

Each paper has a crawlable HTML abstract page, a same-directory PDF, Highwire citation metadata, ScholarlyArticle JSON-LD, a canonical URL, and OpenGraph metadata. The repository also provides `robots.txt` and `sitemap.xml` for discovery.
